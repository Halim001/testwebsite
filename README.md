# Portfolio & Website Template

A modern, responsive personal portfolio and website template crafted with semantic HTML5, CSS custom properties, and vanilla JavaScript.

## Features

- **Hero & Status Header**: Dynamic availability badge, email copy button, responsive navigation.
- **Projects Showcase**: Interactive project cards with tags, descriptions, and live links.
- **Studio & About Sections**: Personal narrative, skill categories, philosophy, and workspace snapshots.
- **Contact & Footer**: Interactive copy-to-clipboard action and social media links.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with WCAG-compliant contrast and smooth transitions.

## Deployment Options

### 1. GitHub Pages (Free & Instant)
1. Go to **Settings** > **Pages** in your repository: [github.com/Halim001/testwebsite/settings/pages](https://github.com/Halim001/testwebsite/settings/pages).
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. Your site will be live at:
   ```
   https://halim001.github.io/testwebsite/
   ```

### 2. Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Import `Halim001/testwebsite`.
3. Keep default settings (Framework Preset: Other / Root Directory: `./`).
4. Click **Deploy**.

### 3. Netlify
1. Go to [app.netlify.com/start](https://app.netlify.com/start).
2. Connect your GitHub account and select `Halim001/testwebsite`.
3. Leave build command empty and publish directory as `./`.
4. Click **Deploy site**.

## Local Development

Simply open `index.html` in your browser or run a local server:

```bash
# Using Python
python -m http.server 3000
```

Then visit `http://localhost:3000`.
